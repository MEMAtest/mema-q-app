### 🎯 Recommended: Custom Domain Setup

For better deliverability and professional appearance:

**Steps:**
1. Go to: https://resend.com/domains
2. Click "Add Domain"
3. Enter your domain: `memaconsultants.com`
4. Add DNS records provided by Resend:
   - **TXT** (SPF): `v=spf1 include:_spf.resend.com ~all`
   - **TXT** (DKIM): Custom key provided
   - **TXT** (DMARC): `v=DMARC1; p=none;`
5. Verify domain
6. Update code:
   - `pages/api/send-results.js:57`
   - `pages/api/leads.js:64`

   Change:
   ```javascript
   from: 'MEMA Consultants <onboarding@resend.dev>',
   ```

   To:
   ```javascript
   from: 'MEMA Consultants <noreply@memaconsultants.com>',
   ```

7. Redeploy: `vercel --prod`

**Estimated Time:** 20 minutes

## 🌍 Custom Domain Setup (Optional but Recommended)

Add a memorable domain for your users:

**Recommended Domain:** `finproms.memaconsultants.com`
**Alternative:** `compliance.memaconsultants.com`

**Steps:**
1. Go to: https://vercel.com/memas-projects-23a0001d/mema-q-app/settings/domains
2. Click "Add Domain"
3. Enter your desired domain
4. Add DNS records to your domain provider:
   - **A Record**: Point to Vercel's IP
   - **CNAME**: Point to `cname.vercel-dns.com`
5. Wait for DNS propagation (5-30 minutes)
6. SSL certificate auto-generated by Vercel

**Benefits:**
- Professional appearance
- Easy to remember
- Better SEO
- Builds trust with users

## 🆘 Support & Troubleshooting

### Common Issues & Solutions

**Issue: Site is slow**
- Check Vercel analytics for bottlenecks
- Review database query performance
- Consider enabling caching headers

**Issue: Emails not delivering**
- Check spam folders
- Verify Resend API key is active
- Review Resend logs: https://resend.com/logs
- Consider custom domain setup

**Issue: Database errors**
- Check Neon dashboard for connection issues
- Verify DATABASE_URL is correct
- Review Prisma logs in Vercel

**Issue: Admin can't login**
- Verify admin key matches environment variable
- Clear browser cache
- Check Vercel env vars are set
